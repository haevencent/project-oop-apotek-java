# Project-oop-apotek-java
Sistem Manajemen Apotek (Pharmacy POS &amp; Inventory)  Aplikasi Sistem Manajemen Apotek berbasis desktop menggunakan **Java**. Sistem ini dirancang untuk mendigitalisasi proses operasional di apotek, mulai dari manajemen data obat, pemantauan stok secara *real-time*, hingga proses transaksi di meja kasir.

Kebutuhan Fungsional:
- Pengguna dapat melakukan login ke aplikasi.
- Sistem dapat menambah, melihat, dan mengubah data Obat (ID, Nama, Harga, Jenis, Stok).
- Sistem dapat melakukan transaksi penjualan dengan menampung lebih dari satu jenis obat.
- Sistem secara otomatis menghitung total harga dan mengurasi atribut stok pada data Obat saat transaksi selesai.
